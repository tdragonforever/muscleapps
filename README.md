# 筋トレメモ

**アプリを開く → https://tdragonforever.github.io/muscleapps/**

ベンチプレスなどの重さ・回数を記録するブラウザアプリ。記録は端末のブラウザに保存され、ボタン1つで Google スプレッドシートの「日次記録」シートに書き込めます（Google でログインしてリンクを貼るだけ）。

- 日付の行があれば → その行の F 列（筋トレ）だけ上書き
- 日付の行がなければ → 日付の並び順（新しい順/古い順）に合わせて行を追加して書き込み
- 書き込む文字の形: `ベンチプレス（20kg×10、40kg×5、60kg×8）`（送る前に手で直せる）

## スプレッドシートとつなぐ（アプリでの操作）

1. Google スプレッドシートのアプリで書き込みたいファイルを開き「共有 → リンクをコピー」
2. 筋トレメモの「設定」に貼り付けて「つなぐ」→ Google アカウントを選んで「許可」

シートは「日次記録」があれば自動で選ばれ、1行目の見出しから「日付」と「筋トレ」の列を見つけます（詳細設定で変更可）。
ログインは約1時間で切れますが、書き込みボタンを押すと自動でログインし直します（窓が一瞬開くだけ）。

## Google ログインの準備（開発者が最初に1回だけ）

アプリが Google にログインするための「クライアント ID」を作って `config.js` に入れます。

1. https://console.cloud.google.com/ を開き、上の「プロジェクトを選択 → 新しいプロジェクト」→ 名前（例: muscleapps）→ 作成
2. 「API とサービス → ライブラリ」で **Google Sheets API** を検索して「有効にする」
3. 「Google Auth Platform（OAuth 同意画面）」→「開始」
   - アプリ名: 筋トレメモ、サポートメール: 自分 → 対象: **外部** → 連絡先: 自分 → 同意して作成
   - 「対象」→ 公開ステータスの「アプリを公開」→ **本番環境**にする（テストのままだと1週間ごとに許可し直しになる）
4. 「クライアント」→「クライアントを作成」→ 種類: **ウェブ アプリケーション**
   - 承認済みの JavaScript 生成元: `https://tdragonforever.github.io`
   - 作成 → 表示された「クライアント ID」（`…apps.googleusercontent.com`）をコピー
5. `config.js` の `googleClientId` に貼り付け

審査を受けていないアプリなので、最初の許可のときに「Google はこのアプリを確認していません」と出ます。自分で作ったアプリなので「詳細 → 筋トレメモ（安全ではないページ）に移動」で進めて大丈夫です。

## Apps Script でつなぐ（Google ログインを使わない場合）

1. 書き込みたいスプレッドシートを開き「拡張機能 → Apps Script」
2. 最初からある中身を消して、[`gas/Code.gs`](gas/Code.gs) の中身を貼り付ける
3. 6行目の `SECRET` を好きな合言葉に変えて保存
4. 右上「デプロイ → 新しいデプロイ」→ 種類「ウェブアプリ」（次のユーザーとして実行: **自分**、アクセスできるユーザー: **全員**）
5. 「デプロイ」→ Google アカウントの承認（「詳細 → 安全ではないページに移動」で進める）
6. 表示された「ウェブアプリの URL」と合言葉を、アプリの「設定 → 詳細設定」に入れて「接続テスト」

## そのほかの機能

- カレンダー（記録した日に印）、7日間・28日間・総合の負荷量、週ごとのグラフ
- おもりは ▲▼ ボタンか数字を上下にスライドして 2.5kg 刻みで調整（タップすれば自由に入力）
- 前回の記録の表示とコピー、推定1RM（重さ ×（1 + 回数/40））、自己ベスト更新の表示
- 休憩タイマー、RM計算表、種目ごとの推移グラフ
- 未送信の日をまとめて書き込み、入力後の自動書き込み（設定でオン）
- 記録のバックアップ（ファイルに書き出し/読み込み）
